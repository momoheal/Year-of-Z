# z年记事（Year of Z）

> 一个"丧尸没有正面出场"的叙事探索游戏 · 中文原创故事 · 纯前端零远端资源

[English README → README.EN.md](README.EN.md)

**《z年记事》** 是一款基于原创中文长篇故事的浏览器叙事探索游戏。**第一幕（第一—四章）与第二幕开篇（第五章）已经可玩**，另有一个独立切片 **《域外探索 · 长夜与八点》**（同一个世界的另一条街，看的是夜晚）。前者：
第一章《出墙》是一次没有枪的出门——撬棍、合格批次、网格围笼和一张纸质名单；
第二章《两公里》推着板车去柳岸里换回七袋米；
第三章《今天不煮了》在旧城东街的临时厨房里，撞上全作**第一场躲不掉的遭遇**——
没有枪、没有连杀、没有追击，只有退、挡，和一把不属于你的刀；
第四章《回执》收束第一幕——没有敌人，对手是手续：回执齐不齐、代签算不算数、料到底用没用上；
第五章《签过的纸》开启第二幕「不能恢复的人」：签过的纸不会留在过去，系统里的"状态"也不等于病情。

> 🌿 **在线游玩**：[momoheal.github.io/Year-of-Z](https://momoheal.github.io/Year-of-Z/)（`main` 更新后由 GitHub Pages 自动部署）。

## ✨ 特性

- **42 个叙事节点 / 五章**：第一章 12 节点（大门交接 → 开侧门 → 南库抉择 → 合格批次 → 观察点之夜 → 回家）、
  第二章 12 节点（板车两公里 → 下穿道 → 柳岸里窗口交接 → 翻车少了一袋 → 临时食堂）、
  第三章 6 节点（出车 → 十七只碗 → 值班室门 → **遭遇战** → 补充询问 → 临时三天）、
  第四章 6 节点（第三天的回执 → 第四天 → 回家不是好了 → 修好的轮子 → 两行记录 → 也有他那一户）、
  第五章 6 节点（窗口不收药 → 收药的人不在 → 压着杯子的那张纸 → 去一趟 → 带了重点人 → 接到与没接到）
- **同行者（梁医生）**：第五章起在路上的场景里真的跟着你走——保持一个说话距离、对话时站定并转头看你、
  掉队太远直接归位而不是穿墙追人；**同行不入队**，不交互、不战斗、没有好感度（跟随逻辑在 `src/follow.ts`，纯函数、可单测）
- **第五章《签过的纸》**：梁医生常驻同行；三处"更省事"的写法会被**退回**——
  先收药再补章、当晚把人带走、把旧表直接盖掉；章末只拿到"可申请复核的病例索引"，**不给自愈结论**
- **第四章《回执》**：全章无战斗，两处"看起来更省事"的写法会被**退回**——让送饭的人代签、
  把没有回执的一批也打上勾；留白不好看，但它是空的，不是错的
- **第三章遭遇战**（唯一战斗）：实时躲闪 + 体力 + "退 → 椅子 → 椅子散架 → 备餐台上的刀"的固定顺序；
  只有一名来人，**不可连杀、不可追击、不可补刀**；被扑倒不是死亡演出，可以从那一刻重来
- **等距正交 3D**：three.js + 低多边形原创几何 + Canvas 程序化材质，**零远端资源**，离线可玩
- **全部 21 个场景均为正式建景**（不再有"占位地面 + 名牌"）：旧楼立面与铁网门、铁路下穿道与卡点、
  泵站便道、柳岸里卸货口、临时食堂、东街职工宿舍、观察处教室、家里那把椅子、工坊里拆了一半的推车、
  维修点空着的第二个工位、网格员办公室的片区图、铁路边码好的箱堆——素材全部按程序生成
- **物理碰撞**：cannon-es（玩家圆形近似、建筑静态盒体、剧情门动态解锁）
- **双端输入**：桌面键鼠（WASD / Shift / E / 点地寻路）与移动触屏，自适应横竖屏
- **四时段光照**：晨 / 午 / 昏 / 夜平滑过渡，随剧情时间推进
- **自动存档**：localStorage，2.6s 节流写入，坏档自动恢复，刷新后可"继续"
- **工坊（Workshop）**：独立叠加层 + 独立存档键，与章节状态**严格隔离**（叙事红线：枪绝不进入第一章世界）
- **积木人仔 / 单焦点平滑相机**：原创基础几何角色拥有独立四肢步态；机位与视点共用阻尼焦点，启停和转向更稳定
- **假 AO / 浮尘粒子 / NPC 剧情站位**：细节打磨持续中
- **域外探索（独立切片 `zone.html`）**：与正传共享世界观与积木质感的夜间搜刮生存——
  **双时钟**（20:00 出门 / 05:30 天亮 / 08:00 核酸）、**噪音即敌**（1–5 级涟漪画在乐高地面上）、
  **六种丧尸 + 幻觉体**、**机动队三方互咬**（枪声引尸 → 被围死 → 战后掉落）、
  **找尸之旅**（被打倒不删档：丢包 + 3 小时 + 折返）、**医疗两本账**（绷带止血 / 抗生素止感染）、
  **占格背包**与**撤离路线表**；**物品与任务全部积木化**（占格 = 凸点数、委托 = 挂牌）。
  独立入口、独立存档键 `yoz.zone.v1`，与章节状态严格隔离（同工坊口径）

## 🎮 快速开始

```bash
npm install        # 安装依赖（Node.js ≥ 18）
npm run dev        # 开发服务器 → http://localhost:5173
```

| 命令 | 说明 |
| --- | --- |
| `npm run dev` | 开发服务器（已允许外部主机访问，兼容沙箱预览） |
| `npm run build` | 类型检查 + 生产构建到 `dist/`（双入口：`index.html` 与 `zone.html`） |
| `npm run preview` | 本地预览生产构建 |
| `npm test` | vitest：114 个用例（叙事内核 37 + 同行跟随 6 + 遭遇战 15 + 域外探索内核 38 + 建景冒烟 9 + 页面接线 9） |
| `npm run verify` | **Playwright 运行时验收**（需先 `npx playwright install chromium`；走完 12 节点关键流程并输出 5 张截图到 `shots/`） |
| `npm run pack` | 构建并打包 `dist/` → `release/yoz-*.tar.gz`（跨平台，纯 Node 实现） |

标题画面点「**域外探索 · 长夜与八点（独立切片）**」，或直接打开 `zone.html`。

一夜 20:00 → 05:30（约 12.7 现实分钟）。WASD 移动 / Shift 疾跑 / Ctrl 潜行 / 左键挥击 /
右键开枪 / **E 长按**交互（搜刮、撬门、开锁）/ Q 扔空罐 / F 手电 / B 背包 / L 任务 / M 地图 / 滚轮缩放；
快捷 1 绷带 · 2 抗生素 · 3 电池 · 4 吃的。设计文档见 [doc/33](doc/33-域外探索-设计.md)。

建议路线：20:00 商业街（搜刮主课堂）→ 21:00 主干道看机动队与丧尸互咬 →
22:00 宵禁 → 22:30 仓库区（重尸把守）→ 23:00 快尸出巢 → 23:30 定居点交货包扎 →
选一条路回家（大路赌一张通行条 / 地道赌一节电池 / 后墙缺口赌一双腿）。

### 操作

- **移动**：WASD / 方向键，Shift 跑步；或点击地面设路标自动步行
- **交互**：靠近人物/物件后按 **E**
- **遭遇战（仅第三章厨房）**：空格 / 鼠标右键 **挡**，J / 鼠标左键 **挥**，E **拿**手边的东西；被按住时连按空格挣开；触屏为右侧「挡 / 挥 / 拿」三键
- **背包 / 任务**：I / Tab；**光照模式**：界面滑杆（自动 · 晨 · 午 · 昏 · 夜）
- **手机**：点地移动，点屏幕上的 E 提示交互（横屏视野更佳）

### 在线游玩（GitHub Pages）

仓库已内置 `.github/workflows/pages.yml`：合并 PR 到 `main` 后，在仓库 **Settings → Pages** 中选择
**Source: GitHub Actions**，每次推送 `main` 都会自动构建 `dist/` 并发布到
`https://<用户名>.github.io/Year-of-Z/`（Vite 已使用相对 `base: './'`，子路径直接可用）。

## 🛠 技术栈

TypeScript · Vite 5 · three.js 0.169 · cannon-es · lucide（图标）· vitest（jsdom 钉在 25.x：新版依赖 Node 22 的内部 API，而仓库声明支持 Node ≥ 18）· Playwright（验收）
无服务端、无数据库、无 CDN 依赖——整个游戏是一个纯静态站点。
