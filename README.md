# z年记事（Year of Z）

> 一个"丧尸没有正面出场"的叙事探索游戏 · 中文原创故事 · 纯前端零远端资源

[English README → README.EN.md](README.EN.md)

**《z年记事》** 是一款基于原创中文长篇故事的浏览器叙事探索游戏。**第一—三章已经可玩**：
第一章《出墙》是一次没有枪的出门——撬棍、合格批次、网格围笼和一张纸质名单；
第二章《两公里》推着板车去柳岸里换回七袋米；
第三章《今天不煮了》在旧城东街的临时厨房里，撞上全作**第一场躲不掉的遭遇**——
没有枪、没有连杀、没有追击，只有退、挡，和一把不属于你的刀。

> 🌿 **在线游玩**：[momoheal.github.io/Year-of-Z](https://momoheal.github.io/Year-of-Z/)（`main` 更新后由 GitHub Pages 自动部署）。

---

## ✨ 特性

- **30 个叙事节点 / 三章**：第一章 12 节点（大门交接 → 开侧门 → 南库抉择 → 合格批次 → 观察点之夜 → 回家）、
  第二章 12 节点（板车两公里 → 下穿道 → 柳岸里窗口交接 → 翻车少了一袋 → 临时食堂）、
  第三章 6 节点（出车 → 十七只碗 → 值班室门 → **遭遇战** → 补充询问 → 临时三天）
- **第三章遭遇战**（唯一战斗）：实时躲闪 + 体力 + "退 → 椅子 → 椅子散架 → 备餐台上的刀"的固定顺序；
  只有一名来人，**不可连杀、不可追击、不可补刀**；被扑倒不是死亡演出，可以从那一刻重来
- **等距正交 3D**：three.js + 低多边形原创几何 + Canvas 程序化材质，**零远端资源**，离线可玩
- **物理碰撞**：cannon-es（玩家圆形近似、建筑静态盒体、剧情门动态解锁）
- **双端输入**：桌面键鼠（WASD / Shift / E / 点地寻路）与移动触屏，自适应横竖屏
- **四时段光照**：晨 / 午 / 昏 / 夜平滑过渡，随剧情时间推进
- **自动存档**：localStorage，2.6s 节流写入，坏档自动恢复，刷新后可"继续"
- **工坊（Workshop）**：独立叠加层 + 独立存档键，与章节状态**严格隔离**（叙事红线：枪绝不进入第一章世界）
- **积木人仔 / 单焦点平滑相机**：原创基础几何角色拥有独立四肢步态；机位与视点共用阻尼焦点，启停和转向更稳定
- **假 AO / 浮尘粒子 / NPC 剧情站位**：细节打磨持续中

## 🎮 快速开始

```bash
npm install        # 安装依赖（Node.js ≥ 18）
npm run dev        # 开发服务器 → http://localhost:5173
```

| 命令 | 说明 |
| --- | --- |
| `npm run dev` | 开发服务器（已允许外部主机访问，兼容沙箱预览） |
| `npm run build` | 类型检查 + 生产构建到 `dist/` |
| `npm run preview` | 本地预览生产构建 |
| `npm test` | vitest：31 个用例（叙事内核 17 + 遭遇战内核 14） |
| `npm run verify` | **Playwright 运行时验收**（需先 `npx playwright install chromium`；走完 12 节点关键流程并输出 5 张截图到 `shots/`） |
| `npm run pack` | 构建并打包 `dist/` → `release/yoz-*.tar.gz`（跨平台，纯 Node 实现） |

### 试玩第三章（跳过前两章）

标题画面点「**第三章试玩 · 直奔东街**」即可：一、二章按默认选择自动补全，直接从东街那天早上开始
（会清除旧存档）。地址加 `?jump=fight` 则直接站进厨房，门随即被拉开。

### 操作

- **移动**：WASD / 方向键，Shift 跑步；或点击地面设路标自动步行
- **交互**：靠近人物/物件后按 **E**
- **遭遇战（仅第三章厨房）**：空格 / 鼠标右键 **挡**，J / 鼠标左键 **挥**，E **拿**手边的东西；被按住时连按空格挣开；触屏为右侧「挡 / 挥 / 拿」三键
- **背包 / 任务**：I / Tab；**光照模式**：界面滑杆（自动 · 晨 · 午 · 昏 · 夜）
- **手机**：点地移动，点屏幕上的 E 提示交互（横屏视野更佳）

### 在线游玩（GitHub Pages）

仓库已内置 `.github/workflows/pages.yml`：合并 PR 到 `main` 后，在仓库 **Settings → Pages** 中选择
**Source: GitHub Actions**，每次推送 `main` 都会自动构建 `dist/` 并发布到
`https://<用户名>.github.io/Year-of-Z/`（Vite 已使用相对 `base: './'`，子路径直接可用）。

## 🛠 技术栈

TypeScript · Vite 5 · three.js 0.169 · cannon-es · lucide（图标）· vitest · Playwright（验收）
无服务端、无数据库、无 CDN 依赖——整个游戏是一个纯静态站点。

## 📁 项目结构

```
├── index.html            # DOM 外壳（UI 面板、标题画面）
├── src/
│   ├── main.ts           # 启动 / 输入 / 存档 / 音频 / 主循环接线
│   ├── story.ts          # 叙事内核：节点拼接、物品、旗帜、存档序列化（全部纯函数可测）
│   ├── data/chapter1-3.ts# 按章拆分的叙事数据（节点、选择、物品、日志）
│   ├── combat.ts         # 第三章厨房遭遇战内核（纯状态机，不依赖 DOM / three.js）
│   ├── world.ts          # 场景/角色/灯光/物理/动画（12 个场景，厨房为精细建图）
│   ├── mapdata.ts        # 碰撞墙与厨房场地单一数据源（构建、战斗与测试共用）
│   ├── workshop.ts       # 工坊叠加层（独立渲染器与存档）
│   └── style.css         # 响应式 UI
├── tests/story.test.ts   # 叙事内核不变量（17 用例）
├── tests/combat.test.ts  # 遭遇战不变量与可玩性回归（14 用例）
├── scripts/
│   ├── verify.mjs        # Playwright 端到端验收脚本
│   └── pack.mjs          # 跨平台 dist 打包（tar.gz）
├── .github/workflows/    # CI（tsc+测试+构建）与 Pages 部署
└── doc/                  # 27+ 篇中文故事/设计文档（见 doc/README.md）
```
