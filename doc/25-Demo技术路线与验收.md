# Demo 技术路线与验收

版本0.1，2026-09-20；实施状态以本文末尾实际验证为准。

## 技术选择

| 层 | 方案 | 理由 |
| --- | --- | --- |
| 运行／构建 | Vite + TypeScript | 纯静态产物，可部署任意静态HTTP站点，资源使用相对基址 |
| 3D | Three.js WebGLRenderer + OrthographicCamera | 平面移动、斜俯视城市、实时光影、独立工坊模型 |
| 碰撞 | cannon-es 动力学世界 | 使用成熟碰撞核心；角色圆形近似，建筑静态盒体，避免手写穿墙检测 |
| UI | 原生DOM + CSS + lucide | 中文对话、任务、背包、日志、设置、移动端摇杆；不引入额外UI框架 |
| 美术 | 原创Three几何 + Canvas生成位图材质 | 首轮可运行资产，无远端图片／版权资源依赖；后续替换手绘贴图和人物 |
| 音频 | Web Audio，用户操作后启动 | 脚步、环境与交互声，无自动播放阻断；可静音 |
| 状态 | 显式节点推进与localStorage版本校验 | 任务不可乱序，剧情存档与工坊隔离，可重置与恢复 |
| 验证 | TypeScript构建、状态单测、Playwright浏览器检查 | 分别检验数据不变量、资源与实际可玩表现 |

## 代码边界

`src/story.ts`：对话、状态、物品和节点；`src/world.ts`：场景、角色、灯光、物理与投影；`src/main.ts`：UI、输入、存档和帧循环；`src/workshop.ts`：独立模型与配件；`src/style.css`：响应式界面。避免把原文直接当作可执行脚本。所有HTML展示动态文本须来自受控数据或通过textContent写入。

## 性能和兼容目标

桌面1280×720以上，移动端390×844及横屏。画布全屏、设备像素比上限1.5，单方向阴影、共享几何材质，夜间光源少量使用；移除离屏装饰不影响叙事。页面失焦暂停输入，时间步上限防止恢复后穿墙。弹窗与工坊暂停角色运动，关闭恢复原节点与位置。

目标桌面稳定60fps、移动端30fps；这是预算而非未经测量的保证。本轮浏览器移动视口仿真不等于真机性能认证。WebGL不可用显示错误与重试；存储不可写仍能本次游玩。音频关闭后不得保留持续声源。

## 验收清单

- 可从新局完成全部章节节点，返回后仍可查看日志。
- 远距不能交互，墙体不能穿越；移动端方向和交互可用。
- 灰灰在投喂后可见跟随，不进入南库；返程有安置记录。
- 清晨、黄昏、夜间可切换，夜间人物、地面与目标仍可辨识。
- 背包随选择更新；刷新恢复节点；重玩需二次确认。
- 工坊三槽切换可见，靶场有命中／后坐反馈，返回章节没有枪。
- 弹窗不穿透，桌面／移动文字不溢出，WebGL画布不空白。
- 本地构建通过；检查浏览器错误、资源、截图和画布像素变化。

## 运行

`npm install`，`npm run dev -- --host 127.0.0.1`。生产构建：`npm run build`；构建结果为`dist`，需HTTP静态服务，不能直接双击入口HTML运行模块。`npm test`验证状态不变量。
