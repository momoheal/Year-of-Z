## 用户确定的方向

- 名称：《Z年纪事》。未来形式为平面射击游戏；当前先完成故事，不先安排战斗场景或写代码。
- 丧尸题材影射疫情封锁的荒诞。核心政府没有崩溃，仍维持最低供给、组织生产与公共服务。
- 城市被划成多个安全区，小区成为日常生活与管制的边界；装甲／钢铁列车承担重要补给和人员转运。
- 机构反应迟钝，使用落后信息，存在欺上瞒下、腐败和资源侵占；不同层级、不同人员的行为不能写成完全一致。
- 补给持续减少，安全区内部信任破裂。主角因生活压力出门，其他安全区因潜伏期和责任风险拒绝接纳。
- 某些官员居住区囤有远超需要的物资，其他安全区却陷入短缺。
- 主角发现部分感染者可以自行恢复，重新审视自己造成的死亡。14落实复核病例，16明确区域医疗与行政层级知情、中央技术联络部门收件以及区域继续压制信息和执行旧清剿口径；不将未知层级一并认定全知。
- 后续包含安全区大火、钢铁列车坠崖、饥饿中的居民走上街头要求开放，最终以荒诞、离奇的境遇收束。
- 列车残骸里有感染迹象消退、神智恢复的被转移者，也有自愿或被迫同行的健康家属。不能把所有乘员都写成完全转化者。
- 主角是普通城市白领：08首次用刀致死，13首次开枪发抖失准，14才掌握自愈确证。主线共三次明确的致死事件；武器13末销还，此后未再领枪；结局仍需面对枪击复核与心理影响。
- 最新要求：第一次探索不带枪，可带刀或撬棍；本次选择撬棍，不把首次探索写成首次杀戮。
- 叙事要靠有张力的画面和行动推进，避免一连串解释设定的对话。保持普通人的身体能力与恐惧。
- “Z年”指丧尸爆发后的每一年，不是统一行政年号，也不新增Z年一、Z年二的纪年制度；既有相对时序不变。
- 抗过敏奶粉支线是现实封锁记忆的虚构化映射；不把新闻细节、真实身份或未经核验结果写成史实。
- 长期结构增加家园线与流浪线：母亲持续透析且主角未感染时，家可作为可返回避风港；母亲死亡、主角感染或家屋不可用时，转入墙外简易居所，伙伴收留必须消耗真实物资。
- 增加马工程师：工程与运输背景，早期宏大叙事有实际能力，后期被具体伤亡和名单纠正，不能只写成笑话。
- 完整三幕通关后解锁真实模式，当前按任一正式结局完成定义：无丧尸，只有被分类、缺乏配给并被带走的病人；需重写反馈和称谓，不能只删除敌人。
- 奶粉任务前移到05返家后、06出发前等待核货的早期空档；许晨无枪、经验不足，危险迫使绕行。详见26，与周立、母亲透析、信息传播及后续公开相连。
- 墙外长期定居增加主动武装求生，可袭击武装流氓、军队目标或探索高危险据点获取更好装备；默认在13后展开为替代路线，新增伤亡与装备必须独立追踪，不能套用普通主线统计。
- 暴恐机动队是安全区外唯一合法武装力量，装备高性能武器并负责肃清、封锁和转运；流浪路线应优先规避，不把正面冲突写成普通战斗。周小姐可用有限身份与调度信息支开机动队，但会承担暴露家人和信用受损的代价。

## 后续游戏设计必须检查

- [ ] 首次出行的物品、动画和教程没有偷偷给主角配枪；撬棍先作为工具出现。
- [ ] 没有在新手段落安排与正文冲突的熟练杀敌、精准射击或首次死亡。
- [ ] 首次致死位于08厨房事件；首次开枪位于13，表现惊慌失准。不能改成熟练处决、精准射击或即时武器奖励。
- [ ] 交互让事件与环境发生变化，不把全部内容改成对话框播放或资料收集。
- [ ] 主角在不知道自愈的阶段，不能使用后期才获得的知识作确定判断。
- [ ] 对感染者的危险、诊断不确定性与恢复可能分别处理；不把一个动作当作医学证明。
- [ ] 存在可见的救助、生产、运输劳动；也能看见利益分配和责任选择，不用一句“系统坏了”替代因果。
- [ ] 补给来源、搬运能力、车辆容量、物料用途和时间成本符合前后文。
- [ ] 母亲的医疗需求、角色受伤和隔离状态不会在下一场景自动消失。
- [ ] 09的记忆空缺、观察与心理支持待接续；不让一次签字、工作或母亲安慰消除创伤，不将记录修订当作调查结案。
- [ ] 东街17名固定用餐者、19名到场者、22名已核配送对象分别记录；三天临时安排与实际送达分开，不能显示为永久供餐已恢复。
- [ ] 支线与选择的后果能追踪，不因一个对话选项让整个地区突然信任主角。
- [ ] 火灾、坠车、恢复者与健康家属的揭露有前置事实，不仅充当煽情奇观。
- [ ] 射击奖励、击杀反馈和失败惩罚不破坏后期对杀戮的反思；具体方案待设计阶段讨论。
