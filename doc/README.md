## 版本规则

- `01` 是已讨论的现行开篇场景稿，保留场景说明与样本文字的混合形式，尚未统一润色成纯小说。
- `02` 保存此前给出的第一章续写正文。
- `03` 为首次探索续篇；`05` 承接回程并收束第一次外出，均保留为可继续修订的故事稿。
- `06` 开始第二次外出，写至柳岸里等待返程接应；`07` 完成返程，交代损耗、入库与首批应急餐发放。
- `08` 核查东街宿舍并开始第三次外出，发生主角第一次用刀造成死亡，结尾在外勤观察处；尚未发生首次开枪或自愈揭露。
- `09` 承接当晚至次日夜间的观察、补充询问与心理余波；东街首批二十二份配送落实，后两日为临时安排，住户状态及转移回执仍待核；许晨尚未返家。
- 以上各条是该章结尾状态。`11—20` 已推进至全书末尾，不能将早期“尚未”当作当前全书进度。
- `11—20` 是一条连续主线，`21` 是互斥或可组合的替代路线；主线六名火灾死亡者、灰灰存活、阿宁存活、赵出卖地点等不可直接移植到不同分支而不重核。
- [早期样本：已送达](archive/00-早期样本-已送达.md)完整保存最初的小说样本，属于历史方案，不与现行版本自动拼接。

- 用户最新约束优先：第一次外出不带枪，本次采用撬棍。早期样本“首次出行领枪”的安排已被替代。
- 后续修改正文时，同时更新变更记录；移动或删除伏笔时必须说明去向。不要无声覆盖已发生事件。
- 前一轮伙伴线回补了03的投喂与运输、05的灰灰照护、09的未同行说明，具体范围见04；当时新增10保存六位伙伴的招募场景、长期关系及分支。“第二幕”不等于已有第二章。
