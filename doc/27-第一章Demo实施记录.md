# 第一章 Demo 实施记录

2026-09-21。范围：现有第一章原型的可玩闭环；正文不改动。

## 本轮要求

- 借鉴《逃离鸭科夫》的斜俯视观察、键盘移动、鼠标朝向、附近交互与背包查看；第一章仍是无战斗的叙事探索。
- 美术采用最简单可实现的原创低多边形几何、平涂材质和 Canvas 标牌。无需下载模型、购买素材或调用图片生成服务。
- 对话逐页完整呈现，完成节点后玩家自行移动；只在返程后连续叙事中复用车辆位置。
- 有墙体碰撞、近距交互、目标方向、自动存档、重开入口、触屏操作与可关闭音效。

## 实现设计与编程约束

沿用 `story.ts` 的章节数据与物品派生；强化存档校验和选择日志。`world.ts` 负责低模场景、碰撞与角色朝向；`main.ts` 管理对话页码、输入和互斥面板；`style.css` 提供紧凑任务卡及移动布局。所有场景对象保留功能语义，后续可以替换模型而无需改剧情。

先补针对交互距离、选择日志和损坏存档的单测，再接入游戏；禁止任意地点 E 键推进、任务后传送、逐帧写 localStorage、用第一张对话代替全部正文。浏览器验证覆盖新局、行走、完整对话、存档恢复和移动布局。验证命令：`npm test`、`npm run build`、Playwright 浏览器操作与截图。

工坊保留为独立试作，本轮第一优先级为第一章闭环。尚未完成的技术验收项必须如实记录。

## 后续影响

第二章可复用输入、对话及状态持久化；第一章的给水／求助选择保留为事实记录。当前画面是低模原型美术，不代表最终角色与建筑质量。未引入《逃离鸭科夫》的任何原始素材。

## 2026-09-22：反馈轮优化（上轮遗留项）

实现并完成 tsc / vitest(12/12) / vite build 验证（沙箱仍无法跑 Playwright，运行观感以本地 `npm run verify` 为准）：

- 假环境光阴影：建筑/载具/雨棚/人物脚下加径向渐变贴片（`aoPatch`，共享一张 CanvasTexture）。
- 库内与雨棚浮尘：`Points` 粒子（90+40 颗），缓慢旋漂与透明度呼吸；仅随场景可见性渲染。
- 人物鸭子走：腿改髋部枢轴组 + 头部成组（`makePerson` userData.legL/legR/head）；步幅沿用上一章 2.2 米/3 步，相位由位移驱动；跑步摆动幅度与身体前倾加大，头部反向微抬保持视线。
- 镜头：平滑跟随（camFocus 插值，切场景直接落位）、移动方向前瞻、站立镜头呼吸；`maxDPR` 字段实装到 renderer。
- 狗子：跟随跑动时小碎步弹跳（y 位移）。
- NPC 随剧情换站位：`setNpcStage(已完成节点数)`——老程/装卸工在侧门开后、呼叫医护、网门观察、返程交接各阶段换位置与朝向；节点完成与读档时同步（main.ts 在完成节点后调用）。

遗留：`buildWarehouse` 门板组坐标构建时两次赋值写法偏糙（行为正确，未清理）；环境热点微光池（glintPool 12 颗）已预建但未接入交互提示，列下一阶段候选。
