## 二、被退回的两种写法（本章的"拒绝式选择"）

前三章的拒绝式二选一考的是"别把没看见的写成事实"，本章换成同一件事的行政版本：

1. **让送饭的人代签**——签的那一栏写的是"住户本人确认"，不是"饭送到了"。
2. **两行一起打勾**——第二批只有一张同用途的单子，连东西摆在哪里都没看见。

两者都不改变任何状态（flags / log / items 均不写入），退回后回到选择页。
C04-01/03/05 不设选择：它们是结果与代价，不是抉择。

## 附二：语感与静物的二次打磨（贴回游戏设计）

依据 doc/23「可读俯视空间 / 克制的内心叙述」：对话面板是**一屏一拍**，不是小说段落。

### 文本

- 第四章全部重排：长段拆成单拍短页，概述句改成现场动作与对白。
  例：「又经过几次复查与评估，医护允许许晨回家……」→「第三次复查做完。医护说可以回家：继续监测，按时复诊。」「调查没有因为放行结束。」
- 关键台词提成独立对白页：`赵网格「少了住户签字。材料得退回来。」`、`冯师傅「名单交给送饭的人就行。」`、
  `陈工「第一行我签。第二行你别替我写。」`、`赵网格「我知道这不算核过。」`。
- 回填前面章节两处超长页：C01-00 老程的任务核对、老郑的语音（拆成四条，更像真的语音条）、
  C02-04 绕路说明与 C02-10 名单争论。
- 新增机制化约束（测试保证，不靠自觉）：
  **叙述页 ≤ 130 字、对白 ≤ 45 字，第四章按新标准 ≤ 95 字**；每个节点 `objective ≤ 40 字`、
  `interactLabel ≤ 10 字`；第四章每个节点至少有一句带说话人的台词。

### 静物

- 交互点前必须有可读的焦点物：家里的椅子挪到进门正对处（C04-02 的交互点就在椅子与桌子之间），
  观察处补一张折叠桌（C03-05 / C04-01 的"续餐材料"摊在上面，配名单、合着的笔记本、半杯水）。
- 新增 14 处**环境注视点**（只读回声，不写事实、不给物品、不推进剧情），覆盖第二—四章全部新场景：
  宣传栏两张压在一起的配送安排、下穿道的积水与踩过去的两块砖、岗亭登记本只有三行、
  柳岸里地秤上米粒压出的白印、食堂"一人一份"下面手写的那行小字、电动车筐里被雨打软的房号、
  观察处卡住的投影幕、家里病历夹着的接送名单、工坊"可拆"的编号牌、维修点空工位的四个固定孔、
  网格员片区图上那个没写人名的红框、路边箱子上他认得的批号。
- 测试同时校验：热点坐标必须落在所属场景外框内、页面 ≤ 120 字、不携带 effects；
  有剧情的场景（除厨房与观察点外）都至少有一处可注视的东西。

验收：`tsc` / `vitest 43` / `vite build` 全绿。
