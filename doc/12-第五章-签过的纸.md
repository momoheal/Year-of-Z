# 第五章：签过的纸

第二幕「不能恢复的人」开始。时间接第四章后数日，章节间仍有往返、休息和母亲的持续治疗。

## 收药的人不在

接收站查回执那天，许晨跟一辆药品交接车同行。他只负责文件核对，药由随车人员管理。灰灰留在物资站；赵拿着两区补录材料，陈工顺路去附近维修点查料。

接收窗口没有收药。

原来具名的医生已调走，新接班人尚不在授权名单。窗口里的人说缺，手却不肯伸出来，叫他们等盖章。

等到配送车必须返程，章没有来。药按原运输要求退回临时医疗点，封签与温度记录一起交接。

坐在门边的医生姓梁，以前看眼科。许晨解释拒收缘由，他先请管理药品的人核验箱子，问能否入原储存条件，再问那边的病人有没有替代安排。

许晨答不上来。

“下回帮我问这个。”梁说。

桌上的旧纸压着杯子，纸角露出“不再散布不实言论”。许晨看了一眼，梁没有遮，反而把杯子挪开了。

早期他在同行的小群里发过异常病例提醒。处理人员说没有统一口径，他造成了恐慌。签字时，有人告诉他只是例行手续，签了就回去工作。

后来正式通知采用了相近的警示，他问过原处理是否撤销。对方说现在忙这些没有意义。

“当时你就知道会恢复？”许晨问。

梁抬眼：“当时连会发展成什么样都不清楚。别替我添本事。”

## 去一趟

许晨没有当晚把他带走。

接下来的两天，赵找到了能补授权的人，药车补齐接收手续，许晨带回两名延误用药者的转诊去向。梁核对后才把值班记录交给接班医护，一张床一张床交代。

“这里有人接了，我跟你们去接收站。”

他把签字纸放进防水袋，动作很仔细。

途经一个职工安全区时，窗口认出梁。里面的女人曾由他给母亲看过眼病，搬开挡门的桶，低声问他愿不愿意进去喝口水。

梁说车上还有别人。她迟疑片刻，把几杯水送到外面，没有让所有人入内。

再往前一站，岗亭听见他的名字，转身按了对讲机。

“带了重点人。”

赵的肩膀立刻绷紧。梁坐在车边等核查，把工作证明打开给人看。等到接收站回电确认任务，太阳已经挪过车顶。他没骂人，接过退回的证件，抹平折起来的一角。

许晨这才明白，那张纸并不是被他收好就留在了过去。

## 接到与没接到

东街的回执在接收站档案柜里找到了一部分。已经接收的人中，有的转去亲属区，有的仍留观，有的又被送往山线。未接的几人有退回原因，只是退回联没传到配给端。

赵把自己的转录错误与后续未核查写进更正说明，要求保留原记录，不把旧表直接盖掉。工作人员让他想清楚，说这样别人会问最初是谁报的。

赵低头把名字签完。

他们也查了旧物流园南库那对母子的交接编号。母亲后来住院，儿子在另一处留观；能确认医护确实接到了人，不能把这两行记录当作以后都平安。

许晨又报出雨棚网门的位置。

接待员翻了几页，说那一带后来并入另一组，自己这里只有清场回执，没有逐人去向。许晨请他登记查询。他没有再追问“是不是都死了”，因为谁也没有能回答的资料。

走廊末端有人在广播里催：状态不变的按旧类别转运，不得自行撤销。

梁停了下来。

“什么叫状态不变？”他问旁边的医护。

对方看了一眼喇叭，说这里讲的不是病情，是系统里的分类。

梁没有立即反驳。他问能否看这批人的交接记录，得到一句申请之后再说。

那天临走前，一名值班护士递来几个复诊编号，说有人比来时好了，可她填“好转”会被退单，要求原感染类别不动。她不肯让许晨拍自己的脸，只愿意提供能申请复核的病例索引。

梁接过纸：“我先去看人。”

许晨以为他们已经查到东街为什么断粮。走出楼时才发现，梁握着的那几行号码，指向的是另一道没有被允许打开的门。
