# Z年纪事：第一幕 Demo 项目设计

版本：0.1，2026-09-20。用户已要求进入游戏设计与实现阶段。本文件是开发依据；小说正文保持原样。阅读基线为00、04、21、22。

## 产品定位

纯前端、Three.js、H5、单人本地存档的俯视斜角叙事探索游戏。参考《逃离鸭科夫》的可读俯视空间、出行准备与带物返程的循环；参考《极乐迪斯科》的粗粝色块、城市生活痕迹与克制的内心叙述。模型、界面、文本独立制作，不使用两部作品的素材、人物或地图。

核心体验：玩家认得表格上的地方，却不认得眼前的处境。工作技能确实能帮助生产，但一次正确交货并不能把所有人的生活写成“已完成”。

## 系统原则

1. 探索循环：出发授权 → 观察现场 → 对话与工具交互 → 记录和物料分类 → 同队运输与交接 → 家庭与社区后果。
2. 不设杀敌经验、掉金币、红名即有罪。第一章不存在攻击输入和生命值损耗；紧张来自封闭空间、响声、等候与不确定的人。
3. 灰灰在亭外投喂后保持距离跟随，仅在园区外侧活动；不进南库安置区，不参与诊断。返程先交工具棚再去食品厂。
4. 库存展示个人水、饼、借用工具及任务凭证；包装托盘由装卸队和车辆搬运，不塞进主角无限背包。
5. 选择改变具体事实：是否给个人水、撬门是否求助、回执如何补记。主线必须完成报告与交接，不将误选变成永久卡关。
6. 不公开“善恶值”。日志保留事实、未确定部分和选择记录；后续伙伴关系可读取这些记录，不能直接推出背叛或死亡。

## 视听目标

全屏正交3D场景，无装饰性预览边框。湿润灰绿地面、褪色白墙、锈红门牌、暖黄工灯与灰青夜色形成多个色系。建筑采用切面可视的舞台式布局、笔触纹理和不规则边缘；前景可遮挡物保持低矮，屋顶不遮关键交互。

可见劳动包括运输车、轮转的列车、厂房烟气与灯光；探索中不是整座城市都停摆。环境声使用浏览器合成低音、脚步与工具声，可静音；无配音，本轮不宣称最终手绘美术或完整音频制作。

昼夜：剧情时段由任务节点推进，保持“清晨出发—午后医护到达—傍晚交货—夜间留观—次日回家”。环境按钮可独立预览清晨／黄昏／夜间；不改变病程、任务计时或旁白事实，返回自动即可随章节光照。

## 工坊边界

工坊为菜单进入的独立试作场景，明确标识“工坊试作”，有独立3D模型、可转动视角、机械／光学瞄具、标准／稳定枪托、灯具三槽。槽位选择改变模型和架空散布、回复速度、重量表现；用无人物的纸靶验证后坐与命中分布。不提供现实装配教程、真实品牌或结构参数。章节返回时仍只有借用撬棍，首次开枪仍属于13正文。

## 非目标与后续影响

本轮没有联网、账户、后端、多人、开放世界、完整感染AI、第二章地图或完整第一幕可玩内容。前端接口按章节拆分，后续先增加第二章搬运与伤情，再制作第三章危机，不能把工坊射击直接接进第一章。原21分支将来分章实现，本轮不以按钮假装完整实现。
