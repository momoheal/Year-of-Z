东街临时厨房的自卫遭遇。正文未改动；本文件记录实现范围、战斗设计、红线自检与遗留项。

## 遭遇战设计（`src/combat.ts` + `world.ts` 渲染 + `main.ts` 输入）

内核是**纯函数状态机**（不依赖 DOM / three.js），因此可以整场用例化跑（见 `tests/combat.test.ts` 14 例）。

- **顺序是故事定死的**：退 → 抓椅子 → 椅子散架 → 被逼到备餐台 → 刀。
  手里举着椅子时拿不到刀；一开始跑去备餐台也拿不到——他还没有想到刀。
- **动作**：移动/冲刺（耗体力）、按住空格（右键 / 触屏「挡」）抬臂挡、J（左键 / 触屏「挥」）挥、E（触屏「拿」）拿手边的东西。
- **来人（冯志远）**：只有一个，行为是 追 → 起势 → 扑 → 收势；扑出去的方向在起跳瞬间锁定，可以被走位躲开。
- **挡的三种结果**：有椅子＝挡开并把他撞退（椅子只扛两下）；空手＝勉强推开一次（很耗体力）；有刀＝抵住一瞬（`clinch`，1.5 秒内挥出去才结束）。
- **被扑住**：不是掉血，是被按住——连按挣开（5 下 / 2.4 秒）；挣不开就是失败。
- **失败**：不是死亡演出，是"他把你按在了地上"，可以从门被拉开那一刻**重来**（不写任何剧情事实、不计战绩）。
- **结束即结束**：`outcome = 'win'` 之后状态机冻结，不能补刀、不能追击、不再产生任何事件。
- **引导**：地面引路箭头与 E 提示始终指向"下一件能拿的东西"；HUD 只有一条体力与一句提示，没有敌人血条。

数值（`TUNING`）：来人 3.05 m/s、扑 7.4 m/s；玩家走 3.3 / 跑 5.2（跑耗 21/s，回 15/s）。
脚本玩家（会退、会挡、会拿）跑完一场约 **17 秒**，作为可玩性回归用例固定下来（>8 秒且 <75 秒）。

## 新增场景

- `kitchen`（精细建图）：长桌与十七只碗（含缠胶带的那只）、备餐台与砧板上的刀和半截白萝卜、

- `dongjie`、`obsroom`：沿用通用占位建图 + 专用道具（铁网门与压缺口的砖、墙边那辆绑着两只塑料筐的电动车；
  观察处的床、收了一半的投影幕、通风门边的询问桌）。

## 红线自检（对照 doc/00、doc/23、doc/24）

- 没有枪：全章无枪械物品、无射击；工坊仍与章节状态隔离。
- 刀不是许晨的，也**没有进过背包**：现场留作记录与调查，未归还（用例固定）。
- 只有一名来人，**不可连杀、不可追击、不可补刀**；没有击杀数、没有战果结算、没有胜利音效。
- 不写咬伤特写、不写血腥细节；倒下只有一个"靠着台沿滑下去"的剪影。
- 本章不揭示自愈；冯师傅的暴露评估不给结论；"他是不是还会起来"这句问句留在原地，没有人回答。
- 十九人是"本次到场"，二十二人是"逐户核实后需配送"，两个数字不相减。
- 陈述环节：未亲见的"咬伤"不能签字确认；记不全的几秒必须写成"顺序不确定"。
